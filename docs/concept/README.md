## A note on research

The level documents start with a short section on the original game: how it
played, how it looked, and what made it memorable. Those sections were
written from established knowledge of these well-documented 1993–2001
classics. Before building a level, its designer should replay or watch a
longplay of the original to check the details and get the feel right (see
the "Research checklist" at the end of each level document).
