## Genre spread
- **Shooters (FPS):** 1, 7, 8, 9, 13, 16, 17, 19, 20, 22 — the homage is direct.
- **Real-time strategy:** 3, 5, 18, 21, 23, 24 — translated into first person:
  you are the commando/hero on the battlefield, you order squads, build on
  plots and call in abilities from a wrist "sidebar".
- **Tactics / squad:** 10, 15 — a drone/overhead camera for orders, played
  in first person.
- **Vehicles / flight:** 2, 6, 11 — vehicle module and 6DOF flight.
- **Action-adventure / RPG:** 4, 12, 14 — platforming, loot, co-op magic.

## Document template
Every level document has the same sections:
1. **The original** — research: gameplay, graphics, what made it memorable.
2. **Homage concept** — premise, story beat, Glitch Lieutenant.
3. **Signature mechanics** — the 2–3 mechanics borrowed and how they map to first person.
4. **Arsenal** — loaner weapons and items; which one becomes the trophy.
5. **Enemies** — original designs that wink at the original roster.
6. **Level flow** — the 20-minute beat sheet.
7. **Secrets & challenge** — 3 floppies, the Golden Joystick challenge.
8. **Look & sound** — palette, rendering features, music direction.
9. **Multiplayer** — co-op notes, versus variant if any.
10. **Memory** — the bauble's memory text.
11. **Test hooks** — what the automated game tests check.
12. **Research checklist** — what to re-watch before building.
